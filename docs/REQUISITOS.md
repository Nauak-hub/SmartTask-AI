# Requisitos do SmartTask AI

## Requisitos funcionais

- RF01: cadastrar uma tarefa.
- RF02: listar todas as tarefas.
- RF03: consultar uma tarefa pelo identificador.
- RF04: atualizar uma tarefa.
- RF05: remover uma tarefa.
- RF06: alterar o status da tarefa.
- RF07: filtrar tarefas por status ou categoria.
- RF08: interpretar uma descrição textual e sugerir dados estruturados.

## Requisitos não funcionais

- RNF01: utilizar Java 21.
- RNF02: seguir arquitetura em camadas.
- RNF03: possuir testes unitários e de integração.
- RNF04: documentar endpoints com OpenAPI.
- RNF05: executar sem depender de API externa.
- RNF06: permitir substituição futura do provedor de IA.
