# Roteiro de apresentação

## 1. Problema
Gerenciar tarefas manualmente exige preencher vários campos. O SmartTask AI transforma uma descrição livre em uma sugestão estruturada.

## 2. Demonstração
1. Abrir o Swagger.
2. Criar uma tarefa manual.
3. Listar as tarefas.
4. Alterar o status.
5. Enviar uma descrição ao endpoint de IA.
6. Mostrar a sugestão produzida.
7. Executar os testes.

## 3. Conceitos de POO
- Encapsulamento na entidade `Task`.
- Abstração nas interfaces.
- Polimorfismo nas implementações substituíveis.
- Composição por meio das subtarefas.
- SOLID e injeção de dependência.
